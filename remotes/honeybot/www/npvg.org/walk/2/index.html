The first page is already written down.

Before this page opened, your terminal printed two lines worth reading:

  • A line starting with LOCAL ARCHIVE. The path after it, up to the parenthesis, is a text file. It holds every file saved at the first stop, each with its size and its fingerprint.
  • A line starting with Captured. final_url=. The number after artifacts= on that line is how many files the first stop saved.

You do not have to take that number on trust. Open a second terminal window and count the fingerprints yourself. Type this, then a space, then paste the path from the LOCAL ARCHIVE line:

grep -c '"sha256"'

The number it prints should match the number after artifacts=. The program reported something, and a second instrument, one the program did not write, checked the report. That is the whole idea of this workshop in one move.

If the two numbers disagree, you have found something real. Keep both lines.

When you are done, go back to the first terminal and type:

CAPTURE
